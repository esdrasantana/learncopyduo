AI-generated multiple-choice questions (A–E) with Anki-style spaced repetition.

- Generation: text, URL, image, PDF → edge function `generate-questions` (model: google/gemini-3-flash-preview) using tool-call structured output.
- Tables: subjects, topics, sources, questions, answer_history, review_schedule, review_settings.
- Scoping: all data isolated by active project (ciclo).
- SRS ratings 1–5 (Esqueci/Difícil/Médio/Fácil/Muito fácil) → configurable intervals (1/3/7/15/30 days default).
- Adaptive: weak-topic detection from incorrect answers feeds "focus" prompt back into generation.
- UI: `/questions` page with tabs Hoje (review queue + new), Gerar, Banco (filters), Desempenho (charts), Config.
